# Zyberlane Design Reference Library

An internal design-reference catalogue, isolated from Zyberlane production and all client systems.

Implementation and verified catalogue are being prepared in this new repository. Original references: https://github.com/gireeshkumarreddy (read-only).

The separate Vercel project is `zyberlane-design-library`, with Vercel Authentication enabled for all deployments. Repository visibility is controlled separately in GitHub settings.
