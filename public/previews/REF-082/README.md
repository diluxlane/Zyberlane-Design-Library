# ATRIUM MTL

Static, dependency-free website for ATRIUM MTL.

Live site: <https://espace-mtl.pages.dev>

## Project structure

- `index.html` contains the page markup, styles, and interactions.
- `assets/fonts/` contains the locally hosted Archivo and Inter fonts.
- `assets/images/` contains the page artwork and grain texture.

## Run locally

Serve this directory with any static file server, then open its local URL in a browser.

```powershell
npx serve .
```

## Deploy

The site is configured as a plain static site: no build command is required and the deployment directory is the repository root.
