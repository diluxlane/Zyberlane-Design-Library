ABOUT THE COLLECTION

References, with context.

This is Dilux’s internal design-selection tool. Full websites are kept separate from focused hero pages and other interface studies so the main collection stays useful for complete website inspiration.

Search is intentionally broader: matching full websites appear first, followed by hero pages and then other relevant reference types such as components, motion, typography, dashboards, or data visualization when those are present in the catalogue.

Permission to study and use the authorized references was supplied by the library owner. Existing notices and third-party asset rights still apply. Complexity and reference type are editorial classifications based on the inspected source.

Select a reference, copy its ID or source link, then start your adaptation in a separate repository. The library itself stays a reference tool.

Preview status describes the visual experience at the recorded check date, not a guarantee of production-ready bookings, payments, account systems, or future availability.
